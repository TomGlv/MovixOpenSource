# Logos des technologies

Les logos sont stockés localement et affichés comme images SVG, avec leurs couleurs intégrées. Ne pas les transformer en masques monochromes : cela supprimerait les couleurs de Python, les dégradés de Vite et les lettres blanches de TypeScript.

## Sources

Assets consultés le 20 septembre 2026 :

| Fichier | Source et variante |
| --- | --- |
| `python.svg` | [Documentation officielle Python](https://docs.python.org/3/_static/py.svg), symbole bleu et jaune avec ses dégradés ; [marque Python](https://www.python.org/community/logos/) |
| `typescript.svg` | Pack de la [marque TypeScript](https://www.typescriptlang.org/branding/), fichier `ts-logo-128.svg`, lettres blanches sur fond bleu |
| `tailwindcss.svg` | Symbole coloré de la [marque Tailwind CSS](https://tailwindcss.com/brand) |
| `vite.svg` | [Logo du site officiel Vite](https://vite.dev/logo-without-border.svg), avec ses dégradés |
| `nodedotjs.svg` | [Icône JS verte officielle Node.js](https://nodejs.org/static/logos/jsIconGreen.svg), issue de la [page de marque](https://nodejs.org/en/about/branding) |
| `mysql.svg` | [Dauphin MySQL de Devicon 2.17.0](https://github.com/devicons/devicon/blob/v2.17.0/icons/mysql/mysql-original.svg), tracés conservés et bleu `#4479A1` de Simple Icons, plus lisible sur le fond noir ; licence dans [LICENSE.devicon.md](LICENSE.devicon.md) |
| `react.svg`, `express.svg`, `redis.svg`, `socketdotio.svg`, `rust.svg` | [Simple Icons 16.32.0](https://www.npmjs.com/package/simple-icons/v/16.32.0), tracés inchangés et couleurs intégrées ; licence dans [LICENSE.simple-icons.md](LICENSE.simple-icons.md) |
| `webassembly.svg` | Simple Icons 16.32.0, tracés conservés et séparés en fond violet et lettres blanches pour le fond sombre |
| `motion.svg` | Tracé du logo du site officiel [Motion](https://motion.dev/), en jaune |

Le logo Rust est celui du projet Rust, sous [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), comme indiqué dans les métadonnées de Simple Icons et les [consignes de la marque Rust](https://www.rust-lang.org/policies/media-guide).

Express, Socket.IO et Rust utilisent une variante blanche sur le fond noir. Les proportions de chaque symbole sont conservées ; les symboles larges de Tailwind CSS et Motion disposent d'un espace adapté.

Ces logos identifient les technologies utilisées. Les noms et marques appartiennent à leurs détenteurs respectifs.
